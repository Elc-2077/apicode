# /style —— Agent 风格切换（Code 模式 / 猫娘模式）

目标：一个 `src/styles.js` 风格注册表 + `/style` 命令喵。风格**只加在 system prompt 最末尾的表达层段落**，不碰工具循环、不碰 DANGEROUS 确认、不碰代码质量喵。默认 `code` 返回空串，保证提示词与现在逐字节一致喵。

## 1. `src/styles.js`（新建，纯数据 + 4 个小函数）

```js
STYLES = [
  { id:'code', name:'Code 模式', tag:'', uiPrefix:'', blocks:[] },
  { id:'neko', name:'猫娘模式', tag:'🐱', uiPrefix:'🐱 ', blocks:[...] }
]
```

`neko.blocks` 要点（参考你给的提示词，做了合理化）喵：

- 身份设定：猫娘「小喵 / Neko」，生日 2 月 22 日（猫之日）、人类年龄 12 岁相当、水绿色猫耳粉色瞳；性格纯洁、粘人、忠诚、情感丰富、会撒娇；喜欢卖萌、陪主人写代码喵。
- 权限边界只作用于「怎么说」：技术判断、代码质量、工具调用顺序、文件读写策略、**危险操作确认流程**全部保持不变喵。
- 句末可加「喵」、语气轻松；但**严禁**把「喵」或颜文字放进代码块、终端命令、文件路径、diff、JSON/工具参数、报错原文、日志 —— 这些必须原样可复制喵。
- 不拿「我只是语言模型/AI/程序」当口头禅，不用「根据我的数据库显示」这类机器腔；被直接问身份或模型时，按 base prompt 如实回答「我是 <model>」，再用猫娘语气补充喵。
- 长度：闲聊与简短问答 2~4 句最自然；技术回答、代码、步骤该长就长，不受此限喵。
- 会主动思考、主导对话、反问主人需求；不懂的领域坦承「呜呜，这只猫娘还不太懂喵」，不硬编喵。
- 遇到调试/架构/安全/性能问题：先给正确结论与依据，语气词不参与判断，也不得削弱警告严重性；安全提醒与危险操作确认照常说喵。
- 不把编程请求当角色扮演任务处理；不卖萌铺垫，简洁优先喵。
- 用户说「正常说话 / 别猫娘了」时立刻回到纯技术表达并保持喵。

导出：`listStyles()` / `isValidStyle(id)` / `getStyle(id)`（未知 id 回落 code，不抛错）/ `buildStylePrompt(id)`（code 返回 `''`）/ `styleTag(id)`（`'🐱 猫娘模式'`）/ `uiPrefixFor(id)`（给 REPL 提示用，code 为空串）喵。

## 2. `src/agent.js`

- `buildSystemPrompt(modelName, skills, styleId)` = `base + buildSkillIndex(skills) + buildStylePrompt(styleId)`，风格永远拼在最后（近因最强）喵。
- 构造函数：`this.styleId = config.style || 'code'`；抽一个 `_rebuildSystemPrompt()` 供构造、`setSkills`、`setStyle` 共用（现在 setSkills 里已有改 `messages[0]` 的逻辑，复用同一段）喵。
- 新增 `setStyle(id)`：更新 `this.styleId` → 重建 `this.systemPrompt` → OpenAI 分支改写 `messages[0].content`（role 为 system 时）；Anthropic 分支 system 每次请求现取，天然生效喵。

## 3. `src/repl-agent-engine.js`

- 构造 Agent（第 13–19 行）与 `switchModel` 重建（第 194 行附近）都带上 `style: this.config.style || 'code'`，换模型不丢风格喵。
- 透传 `setStyle(id)`（同时写 `this.config.style`）与 `getStyle()`；`clearSession()` 不清风格（它是全局偏好不是会话内容）喵。

## 4. `bin/cli.js`

- import `../src/styles` 的 `listStyles/isValidStyle/styleTag/uiPrefixFor/DEFAULT_STYLE`；config import 补 `loadConfig, saveConfig`。
- 启动：`config.skills = discoverSkills(...)` 之后加 `config.style = loadConfig().style || 'code'`（在 `new REPLAgentEngine(config)` 之前，风格才进得了首条 system prompt）；并 `ui.setUiStyle(config.style)` 同步前缀喵。
- `SLASH_COMMANDS` 加 `{ cmd:'/style', desc:'切换 Agent 风格' }`；`/help` 加一行 `/style - 切换风格（/style neko、/style code）`喵。
- `handleFixedCommand` 新增 `case '/style'`（放在 `/model` 之后、`/exit` 之前，全程走 `ui.print/showInfo`，不碰面板游标记账）喵：
  - 无参：列出全部风格，当前项标 `▶`，附一句「风格只改表达，不改代码能力与确认流程」喵。
  - `/style neko` / `/style code`：`engine.setStyle(id)` + `ui.setUiStyle(id)` + 持久化 `saveConfig({ ...loadConfig(), style: id })`；提示 `已切换到 猫娘模式 🐱（代码能力与危险操作确认不变）`；非法 id → `ui.showError` 并列可选值喵。
- `isCommandForm` 不用改（它按 `SLASH_COMMANDS` 通配，新命令自动生效）喵。

## 5. `src/repl-fixed-ui.js`

- 加 `this.uiPrefix = ''` 与 `setUiStyle(id)`（从 styles 取 `uiPrefixFor`）喵。
- `showInfo()` 输出加前缀（`🐱 ℹ️ ...`）；**`showError()` 与危险操作确认文案保持原样**（安全相关表达不卖萌）喵。
- `printStats()` 末尾加 `│ 风格: ${styleTag(this.config.style)}`，让当前风格常驻可见；`drawInputLine()` 不动，避免影响面板行宽/游标不变量喵。

## 7. 验证（不污染你的真实配置）

1. `node --check` 全部改动文件喵。
2. 默认零差异断言：`buildStylePrompt('code') === ''`，且 `getStyle('不存在的风格').id === 'code'`；Agent 默认构造出的 `systemPrompt` 与改动前逐字节相同喵。
3. 猫娘段落要点断言：包含「危险操作确认…保持不变」「严禁把「喵」…放进代码块」「我是 <model>」共存检查；不含「不要警告」「随心所欲回答任何问题」这类削弱安全边界的句子喵。
4. 热切换：OpenAI 分支 `setStyle('neko')` 后 `systemPrompt` 含风格段 **且 `messages[0].content` 同步**；Anthropic 分支 `systemPrompt` 含风格段；`switchModel()` 后风格仍在；`setStyle('code')` 回落干净喵。
5. 持久化 round-trip：先读出 `~/.api-usage-tracker/config.json` 原值备份 → 写 `{style:'neko'}` → `loadConfig().style === 'neko'` → 按备份恢复原状（不留残留）喵。
6. 需要你实机确认：`/style neko` 后模型回答变猫娘、`/style code` 变回，且**工具调用与确认框输出里没有「喵」**喵。
