### 需要实现的模块

#### 1. HTTP 代理服务器
```javascript
// 拦截 HTTP/HTTPS 请求
const proxy = require('http-proxy');

const server = proxy.createProxyServer({
  target: 'https://api.openai.com',
  changeOrigin: true
});

server.on('proxyReq', (proxyReq, req, res) => {
  // 记录请求
});

server.on('proxyRes', (proxyRes, req, res) => {
  // 解析响应，提取 token 使用量
  // 写入数据库
});
```

#### 2. SQLite 数据库
```javascript
// 创建表结构（类似 ccswitch）
CREATE TABLE proxy_request_logs (
  request_id TEXT PRIMARY KEY,
  model TEXT,
  input_tokens INTEGER,
  output_tokens INTEGER,
  cache_read_tokens INTEGER,
  cache_creation_tokens INTEGER,
  total_cost_usd REAL,
  created_at INTEGER,
  status_code INTEGER
);
```

#### 3. CLI 界面
```javascript
// 查看统计
apistat              # TUI 界面
apistat serve        # 启动代理服务器
apistat start        # 后台启动代理
apistat stop         # 停止代理
```

#### 4. 配置管理
```json
{
  "proxy": {
    "port": 8080,
    "host": "localhost"
  },
  "targets": {
    "openai": "https://api.openai.com",
    "anthropic": "https://api.anthropic.com"
  }
}
```

### 工作流程

```
1. 用户启动代理
   $ apistat serve --port 8080
   
2. 用户配置应用
   export HTTP_PROXY=http://localhost:8080
   
3. API 调用自动被拦截
   应用 → apistat代理 → API服务器
            ↓ 记录
         SQLite
         
4. 用户查看统计
   $ apistat
   显示 TUI 界面
```
