### 2. 登录时直接选择模型

```javascript
// 返回包含 selectedModel 的配置
return { ...api, selectedModel };

// 主流程中判断

  model = await selectModelForExisting(apiConfig);

```

### 3. 输入框渲染优化
```javascript
updateInput(input) {
  this.currentInput = input;
  
  // 完全清空行
  term.moveTo(1, inputY);
  term.eraseLine();
  
  // 重绘内容
  term.green('> ');
  term(this.currentInput);
  
  // 确保光标位置
  term.moveTo(3 + this.currentInput.length, inputY);
}
```
